# Ahmed Osama — Personal Blog

> **Live site → [ahmedosamaali.github.io/Blog](https://ahmedosamaali.github.io/Blog/)**

My personal space for writing about software engineering, technical deep-dives, career growth, and whatever else I find worth putting into words.

---

## What you'll find here

- **Tech** — engineering decisions, tools, and things I've built or learned
- **Tutorials** — practical guides with real code examples
- **Career & Growth** — lessons from working in the industry
- **Personal** — occasional thoughts outside of code
- **Thoughts** — raw ideas and opinions still taking shape

---

## Built with

React 18 · Vite · Tailwind CSS · Framer Motion · Supabase · Deployed on GitHub Pages

---

## Running locally

```bash
npm install
npm run dev
```

Posts are loaded from [Supabase](https://supabase.com) when configured, or fall back to local seed data otherwise.
